# Wedding ERP 受入テストチェックリスト（W8）

現場スタッフによる受入テスト用。各項目を実際に操作し、□ にチェックを入れてください。
問題があった項目は「メモ」に内容を記入してください。

前提: `npm run db:setup` でデモデータを初期化した状態から開始。パスワードはすべて `wedding2026`。

## 1. 認証・権限（F-01, F-17）

- [ ] tera@azon.jp でログインできる／誤ったパスワードでは入れない
- [ ] ログアウト後、URLを直接開いてもログイン画面に戻される
- [ ] ren.t@example.com（新郎）でログインすると自分の結婚式だけが見える
- [ ] florist@example.com（装花業者）では発注タブに自社宛の発注のみ表示される
- [ ] chef@example.com（料理長）は料理タブの編集ができ、見積タブが見えない

- [ ] 今日の予定に打ち合わせ・搬入・試着が時刻順に表示される
- [ ] 新着チャットをクリックすると該当案件のチャットが開く

## 5. 見積（F-06）
