# 新本番VPS（os3-314-46741.vs.sakura.ne.jp）セットアップ手順

作成: 2026-07-09。旧本番 os3-376-21308 からの移行。各ステップを**上から順に1つずつ** Mac（apple@）のターミナルで実行する。
パスワードやAPIキーはこの手順書に書かない（サーバー上で生成 or 実行時に入力）。

## Step 0. SSH鍵の登録（以後パスワード入力が不要になる）
```bash
ssh-copy-id ubuntu@os3-314-46741.vs.sakura.ne.jp
```
（ubuntuのパスワードを1回だけ入力）

## Step 1. Node.js 20 + pm2 + sqlite3 のインストール
```bash
ssh -t ubuntu@os3-314-46741.vs.sakura.ne.jp 'curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt-get install -y nodejs sqlite3 && sudo npm i -g pm2 && node -v && pm2 -v'
```

## Step 2. Caddy（HTTPSリバースプロキシ）のインストール
```bash
ssh -t ubuntu@os3-314-46741.vs.sakura.ne.jp 'sudo apt-get install -y debian-keyring debian-archive-keyring apt-transport-https curl && curl -1sLf https://dl.cloudsmith.io/public/caddy/stable/gpg.key | sudo gpg --yes --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg && curl -1sLf https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt | sudo tee /etc/apt/sources.list.d/caddy-stable.list >/dev/null && sudo apt-get update && sudo apt-get install -y caddy && caddy version'
```

## Step 3. コードの転送（rsync・除外リスト厳守）
```bash
rsync -av --exclude node_modules --exclude .next --exclude prisma/dev.db --exclude storage --exclude .env --exclude backups ~/Documents/wedding-erp/ ubuntu@os3-314-46741.vs.sakura.ne.jp:~/wedding-erp/ | tail -3
```

## Step 4. .env の作成（SESSION_SECRETはサーバー上で自動生成）
```bash
ssh ubuntu@os3-314-46741.vs.sakura.ne.jp 'printf "DATABASE_URL=\"file:./dev.db\"\nSESSION_SECRET=\"%s\"\n" "$(openssl rand -hex 32)" > ~/wedding-erp/.env && chmod 600 ~/wedding-erp/.env && grep -c . ~/wedding-erp/.env'
```
※ Googleログイン・freee連携を使う場合は、後日 GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET / FREEE_CLIENT_ID / FREEE_CLIENT_SECRET を**寺沢さん自身で** .env に追記（旧サーバーの .env は失われているため、Google Cloud / freee の管理画面で再発行）。
※ **DEMO_MODE は本番に書かない。**

## Step 5. 依存インストール → DB作成 → ビルド → 起動
```bash
ssh ubuntu@os3-314-46741.vs.sakura.ne.jp 'cd ~/wedding-erp && npm install 2>&1 | tail -1 && npx prisma db push 2>&1 | tail -2 && npm run build 2>&1 | tail -3 && pm2 start npm --name wedding-erp -- start && pm2 save'
```

## Step 6. OS再起動時の自動起動（pm2 startup）
```bash
ssh -t ubuntu@os3-314-46741.vs.sakura.ne.jp 'sudo env PATH=$PATH:/usr/bin pm2 startup systemd -u ubuntu --hp /home/ubuntu && pm2 save'
```

## Step 7. Caddy設定（HTTPS化）
```bash
ssh -t ubuntu@os3-314-46741.vs.sakura.ne.jp 'printf "os3-314-46741.vs.sakura.ne.jp {\n  reverse_proxy localhost:3000\n}\n" | sudo tee /etc/caddy/Caddyfile && sudo systemctl reload caddy && sleep 3 && curl -sk -o /dev/null -w "%{http_code}\n" https://localhost'
```

## Step 8. 初期データ投入（カタログ69品目・テンプレ15本・管理者）
```bash
ssh ubuntu@os3-314-46741.vs.sakura.ne.jp 'cd ~/wedding-erp && node scripts/rebuild-catalog-with-photos.cjs 2>&1 | tail -2 && node scripts/seed-template-packs.cjs 2>&1 | tail -2'
```
管理者アカウント（パスワードは12文字以上を**実行時に自分で決めて**入力）:
