# EVENTOS（仮）— イベント業界 案件管理システム 仕様書たたき台

CEREMOS（wedding-erp）をフォークして、イベント制作会社向けの案件管理システムをつくる。
対象機能：**見積もり／機材管理／バーチャート／香盤表／台本／車両管理／シフト**

## 1. 基本方針

- コード方針：**wedding-erp をフォークして event-erp として独立**（CEREMOSには影響させない）
- 技術：Next.js 14 + Prisma + SQLite、pm2 + Caddy（同一VPSのポート3001、https://…:8443）
- CEREMOSの「会場×時間帯の重複チェック」を**機材・車両・スタッフ×期間の重複チェック（引当）**に転用する

## 2. 流用と改修（既にあるもの）

| 機能 | CEREMOSの元 | 扱い |
|---|---|---|
| 案件管理 | Case（種別party/ceremony対応済・仮予約・重複チェック） | ほぼそのまま（イベント名主体に） |
| **見積もり** | 見積テンプレ・値引項目・Ver管理・A4/A3印刷 | テンプレをイベント向け料金表に差替 |
| **バーチャート** | 進行表（時間比例・4列・ドラッグ・テンプレ保存） | そのまま |
| **香盤表** | 香盤表印刷 | そのまま |
| **台本** | 進行台本・音響台本＋🎚再生プレイヤー（波形・F.I/F.O・映像小窓） | そのまま（イベント本番で活躍） |
| 請求・入金 | 請求書・入金管理 | そのまま |
| 発注 | 外注業者・発注書 | そのまま（協力会社・レンタル元） |
| 顧客 | セルフ登録・承認・チャット | 法人クライアント向けに文言調整 |
| 席次表・ブライダル楽曲DB・ヒヤリング30問 | ブライダル固有 | **削除**（コードから外す） |

## 3. 新規で作るもの

### ① 機材管理
- 機材マスタ：カテゴリ（音響/照明/映像/電源/什器…）・型番・数量（or シリアル個体）・保管場所・写真
- 案件への機材アサイン：品目×数量×期間（搬出日〜返庫日）
- **重複チェック**：同一機材の同時期アサインで在庫数を超えたらブロック（会場重複チェックの転用）
- 帳票：**積込リスト（ピッキングリスト）** 案件別・カテゴリ順

### ② 車両管理
- 車両マスタ：車種・ナンバー・最大積載・車検/点検期限（期限接近アラート）
- 配車：案件×日付×車両×ドライバー、重複ブロック
- 帳票：**配車表**（日別）

### ③ シフト管理
- スタッフ×日付のシフト（出勤/休み/案件アサイン）
- 案件のリソースタブと連動（案件に入れたスタッフは自動でシフトに反映）
- 月間シフト表（画面＋印刷）、同日ダブルアサイン警告

## 4. 要確認

- ① 機材の単位：シリアル個体管理（1台ずつ追跡）or 数量管理（同型をまとめて）？
- ② 規模感：スタッフ何名・機材何品目・車両何台くらい？
- ③ シフトの粒度：日単位でよい？（時間帯・現場入り時間まで管理する？）
- ④ 機材の外部レンタル（借りてくる）も管理する？（発注と連動）

## 5. 段階計画

- **Phase 1**：フォーク＋ブライダル固有機能の削除＋機材管理（マスタ・アサイン・重複チェック・積込リスト）
- **Phase 2**：車両管理＋配車表
- **Phase 3**：シフト管理＋月間ビュー＋各種帳票仕上げ
