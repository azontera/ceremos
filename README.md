# CEREMOS — Wedding Management Platform（結婚式場 運営基盤）

設計ドキュメント v1 に基づく実装。**基盤＋主要画面**（認証 / RBAC / ダッシュボード / 案件・顧客管理）を含みます。

## 技術スタック

- Next.js 14（App Router）+ TypeScript
- Prisma + SQLite（→ PostgreSQL へ移行可能な設計）
- 認証: 署名付きJWT Cookie（jose + bcryptjs）
- デザイン: 承認済みHTMLプロトタイプのデザイントークンを移植

## セットアップ（初回のみ）

Node.js 18 以上が必要です。

```bash
cd wedding-erp
npm install          # 依存パッケージのインストール
npx prisma db push   # SQLite データベース作成
node prisma/seed.cjs # デモデータ投入
npm run dev          # 開発サーバー起動 → http://localhost:3000
```

※ `npm run db:setup` で db push + seed をまとめて実行できます。

## 実装済み（W1〜W8 全工程完了）

### 次期開発計画 A〜E（docs/次期開発計画.md 参照）

- **A. 部制廃止**：開始〜終了時刻ベースに移行（重複は会場×時間帯の重なりで判定）。カレンダーの日付クリックで日別バーチャート（/day/日付）
- **B. マスタ整備**：初期会場8件、案件種別・間柄・部門の選択肢マスタ（管理画面「選択肢マスタ」）。自由記載会場は「外部会場」として自動登録
- **C. 顧客アカウント**：プランナーが案件ページの「お客様アカウント」からメール＋パスワードを発行して案件に紐付け（セルフ登録・承認フローは廃止）
- **D. 請求・入金**：案件の「請求・入金」タブで支払予定＋請求書（draft→sent→paid）。請求書A4印刷（振込先は「設定」で変更）・見積A3横一覧印刷・ダッシュボード未入金アラート
- **E. 業者マスタ**：業者はスタッフが管理するマスタ（ユーザー・権限画面）。業者宛の発注書一括印刷は /print/vendor/[業者ID]（業者ログインは廃止）

## 本番運用へ向けた既知の簡易実装（MVP判断）

- PDF出力：「印刷ビュー＋ブラウザのPDF保存」方式（依存パッケージ不要）。本番はサーバーサイド生成（Playwright）へ差し替え可能
- リアルタイム同期：ポーリング方式（チャット4秒・当日運営3秒）。本番は Supabase Realtime / Pusher へ
- バックアップ：SQLiteファイル（prisma/dev.db）のコピーで代替。本番はマネージドPostgreSQLの自動バックアップ＋PITR
- パスワード変更：サイドバー「🔑 パスワード変更」から自分で変更可能（8文字以上・英字＋数字）。管理者による再設定も可
- バックアップ：`npm run backup`（backups/ にDB＋添付を14世代保持）。cron例は scripts/backup.sh 冒頭を参照

## PostgreSQL への移行

`prisma/schema.prisma` の `provider = "sqlite"` を `"postgresql"` に変更し、`.env` の `DATABASE_URL` を接続文字列に差し替えて `prisma db push`。ステータス系 String カラムは enum 化を推奨（スキーマ内コメント参照）。
